# Domain Docs

This is a single-context repository.

Before exploring domain behavior:

- Read root `CONTEXT.md`.
- Read relevant ADRs under `docs/adr/` when that directory exists.
- Proceed silently when an optional document does not yet exist.

Use canonical terms from `CONTEXT.md` in issues, specs, tests, and code.
Do not replace them with synonyms that the glossary explicitly avoids.

If a proposed change conflicts with an ADR, identify the conflict explicitly
instead of silently overriding the recorded decision.
